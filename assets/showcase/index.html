OmniDiff Fast, robust, accurate content-aware diffing. Real changes to code, PDFs, fonts, archives and pictures, each shown as diff reports it and as OmniDiff does. Install

Each diff here was computed ahead of time by the omnidiff command-line tool and recorded; your browser only replays it: code in a port of the terminal viewer, other content as the terminal viewer drew it. This is not an online service. Please install the tool.

Keys as in the real viewer: n/p next and previous change, / search, M render options, c colors, ? help. ←/→ step through what OmniDiff shows; pictures are drawn as a terminal with a graphics protocol draws them. The address bar links to what is on screen.
