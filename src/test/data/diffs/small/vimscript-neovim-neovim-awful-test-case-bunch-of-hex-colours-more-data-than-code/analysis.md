## The change

A regenerated Vim colour scheme (zellner.vim, Colortemplate output). Before, the 65 `hi` lines with
gui colours were at top level (lines 35-99), and the cterm colours were in a separate
`if s:t_Co >= 256` block (lines 101-178). After, each top-level line carries both
(`hi Normal guifg=#000000 guibg=#ffffff guisp=NONE gui=NONE ctermfg=16 ctermbg=231 cterm=NONE
term=NONE`,
after lines 40-104). The 256 block is replaced by `if s:tgc || s:t_Co >= 256 / finish / endif`.
The `hi! link` lines are re-sorted, and the header comments are updated. `description.md`: "Requires
N:M mapping". The ground truth has no multi-map groups, though: it maps each gui line to its
merged line, and it leaves the before colour blocks ungraded.

## Mapping

1,072 mismatches (761 visible). Before-side rows 35-99 account for 1,023 of them.

- Old gui lines deleted, 727 visible and 296 invisible. Every node of the 65 top-level `hi`
  statements at before lines 35-99 (`hi`, the group name, each `guifg=...`, `=`, value) is deleted
  (op Delete, reason `APTED("fast_fallback")`). The ground truth maps each statement
  MatchButNotIdentical to the merged after line with the same group (`highlight_statement:10` ->
  `:14` for `Normal`), keeps the old attributes Identical, and inserts the new ones. No after-side
  nodes of those lines are reported as wrongly mapped, so omnidiff inserts them wholesale. Every one
  of these lines changed, so no whole-subtree hash is shared. The gap between anchors (`diff`:
  `34,176c36,106`) also differs in length on the two sides (65 statements plus the 256 block,
  against the re-sorted links, 65 statements and the new `if`). The phase 6 fallback
  (`resolve_residual_forest_via_myers_lcs`) resolves unequal gaps by "kind-only and similarity
  anchors, then replace atomically". The all-Delete result fits the atomic replacement; which branch
  fired was not verified. `matcher`.
- Header comments, 4 visible. The `Website:`, `Last Change:` and `Generated by Colortemplate`
  comment lines (before 5, 7, 9) changed text, and the `" Nvim uses g:terminal_color_{0-15} instead`
  comment moved out of the first `if` block (before 21, after `comment:11`). omnidiff deletes all
  four (same reason). A comment is a single leaf, so an edited or re-parented comment has no
  identical-hash partner. `matcher`.
- Attribute provenance, 19 visible and 9 invisible. In merged after lines 53, 61, 72, 93 and 101,
  omnidiff maps a few new attributes to equal ones in the old colour blocks:
  `ctermfg=NONE`/`ctermbg=NONE` to the 256 block (before 126, 137, 168, 171), and
  `term=bold,reverse,underline` (after 61) to before 334 in the `t_Co >= 0` block. All 28 are
  `MovedSubtree` (a fully deleted attribute paired with a byte-identical fully inserted one). The
  ground truth inserts them. The values did come from those lines, so both
  readings are defensible. It is the N:M nature that `description.md` mentions. `ambiguous`.
- New guard, 4 visible and 2 invisible. omnidiff maps `s:t_Co >= 256` in the new `if s:tgc || s:t_Co
  >= 256` (after 106) to the condition of the removed `if s:t_Co >= 256` (before 101), by
  `MovedSubtree` (the byte-identical expression, deleted on one side and inserted on the other),
  not by the fallback. The ground truth inserts it. `ambiguous`.
- Identical line inserted, 7 visible and 4 invisible. After line 118 `hi CursorLine ctermfg=NONE
  ctermbg=NONE cterm=underline` (in `if s:t_Co >= 16`) is byte-identical to before line 183 in the
  same block. omnidiff pairs its `ctermfg=NONE`, `ctermbg=NONE` and the value `underline` with
  before line 183's by `MovedSubtree`, not by the fallback; where the statement itself goes is not
  in the evidence (it is ungraded). The ground truth has `insert_with_children` for its two
  attributes and `insert` for `underline`. Before line 183 is ungraded, like the rest of the before
  colour blocks (`if_statement:2`-`:5`), which is why `graded` is 4,114 of 9,791 nodes.
  `ground-truth` (and the partial grading is a `grading-artifact`).

Reasons for the "with children" mismatches re-read on 2026-10-13 after the test helper began
printing them.

## Verdict

- Primary cause: `matcher`
- Other causes: `ambiguous`, `ground-truth`, `grading-artifact`
- Where a fix would go: phase 6 residual resolution in src/diff/apted/common/residual.rs. An unequal
  gap of changed sibling statements should be aligned by similarity (same `hl_group`, kept
  attributes) instead of being replaced atomically. Header comments need similarity pairing of
  edited comment leaves.
- Ground truth questionable: yes: after line 118 is byte-identical to before line 183 in the same
  `if s:t_Co >= 16` block, yet its attributes are marked inserted. The before colour blocks are left
  ungraded, so 5,677 nodes are not graded.
