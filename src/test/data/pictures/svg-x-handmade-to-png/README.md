# Sample provenance

- **Sample type:** handmade
- **Formats:** SVG → PNG
- **Research dataset:** pictures

`before.svg.test`/`after.png.test` in this directory were authored by hand for the SVG graphical
diff work (issue #108), not copied from a source repository: they are omnidiff's own test input
under its AGPL-3.0 license. The two sides draw the same 32x32 red square, in different formats, to
pin that a pair is compared by what it draws, not by what its bytes are.
